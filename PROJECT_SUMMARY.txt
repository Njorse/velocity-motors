DESCRIPCIÓN GENERAL
-------------------
Velocity Motors es una plataforma web profesional para una concesionaria 
automotriz premium del mercado peruano. Combina una Landing Page de alto 
impacto visual (diseño "Brutalist Automotive" dark-mode) con un Asistente 
Virtual inteligente capaz de mantener conversaciones naturales, capturar 
leads de clientes interesados y disparar automatizaciones en tiempo real.

El sistema está compuesto por 4 capas principales:
  1. Landing Page pública (React/Vite)
  2. Agente conversacional con IA (Groq + Llama 3.3)
  3. Base de datos y autenticación (Supabase)
  4. Automatización externa (Make.com vía Webhooks)

COMPONENTES TÉCNICOS (DETALLE)
================================================================================

1. FRONTEND — LANDING PAGE (React + Vite + Tailwind)
   ─────────────────────────────────────────────────
   • Diseño: "Brutalist Automotive", fondo zinc-950, acentos en rojo (#dc2626).
   • Tipografía: Montserrat (títulos), Inter (cuerpo).
   • Componentes: Navbar, HeroSection (carrusel), BrandDNA, Showroom 
     (catálogo con filtros por marca), FinanceCalculator, Footer.
   • ChatWidget: Widget flotante con reconocimiento de voz nativo del 
     navegador (Web Speech API) y síntesis de voz (Text-to-Speech).
   • Responsive: Diseño adaptable a móvil, tablet y escritorio.

2. FRONTEND — PANEL DE ADMINISTRACIÓN (/admin)
   ─────────────────────────────────────────────
   • Login.jsx: Formulario con Glassmorphism, usa signInWithPassword().
     SIN registro público. Solo admin creado manualmente en Supabase.
   • ProtectedRoute.jsx: Wrapper que verifica getSession() de Supabase.
     Si no hay sesión activa, redirige a /login.
   • Dashboard.jsx: Tabla de leads con KPIs (Total / Hoy), botón 
     "Exportar a Excel" usando librería xlsx.
   • Seguridad: Cada fetch al backend lleva header Authorization: Bearer.

3. BACKEND — API (FastAPI + Python)
   ─────────────────────────────────
   • main.py: Archivo único con toda la lógica del servidor.
   • Endpoints:
     - POST /chat-voz: Recibe texto del usuario, envía al LLM con 
       historial de sesión y System Prompt, devuelve respuesta.
     - DELETE /sesion/{id}: Limpia el historial de una sesión.
     - GET /api/leads: PROTEGIDO con HTTPBearer. Valida JWT contra 
       Supabase (auth.get_user). Devuelve lista de leads ordenada.
   • Sesiones: Diccionario en memoria (sessions: dict[str, list]).
   • Variables de entorno: GROQ_API_KEY, SUPABASE_URL, SUPABASE_KEY.

4. INTELIGENCIA ARTIFICIAL (Groq API + Llama 3.3 70B)
   ────────────────────────────────────────────────────
   • Modelo: llama-3.3-70b-versatile (procesado en la nube de Groq).
   • System Prompt: Personalidad de asesor de ventas premium, con reglas
     anti-jailbreak, memoria de conversación y flujo de conversación guiado:
     Modelo → Fecha → Nombre → WhatsApp (en ese orden, paso a paso).
   • Contexto de Inventario: Catálogo real con marcas, modelos y precios
     inyectado directamente en el prompt para cotizaciones precisas.
   • Tool Calling (Function Calling):
     - guardar_lead_test_drive(nombre, whatsapp, modelo_auto, fecha_test_drive):
       Se dispara cuando la IA recolecta los 4 datos.
       Guarda en Supabase + envía a Make.com.
     - finalizar_conversacion(): Se dispara cuando el usuario se despide.
       Limpia la sesión y bloquea el chat.

5. BASE DE DATOS Y AUTENTICACIÓN (Supabase)
   ─────────────────────────────────────────
   • Tabla "leads": id (int8), nombre (text), whatsapp (text), 
     modelo_auto (text), fecha_test_drive (text), created_at (timestamptz).
   • Auth: Usuario administrador creado manualmente desde el panel de
     Supabase (Authentication > Users > Add User). No hay signup público.
   • JWT: Cada sesión de admin genera un access_token que se envía al 
     backend para autorizar la lectura de leads.

6. AUTOMATIZACIÓN (Make.com — Webhooks)
   ─────────────────────────────────────
   • Trigger: Cada vez que la IA captura un lead (4 datos completos),
     el backend envía un POST al webhook de Make.com con:
     { "nombre", "whatsapp", "modelo_auto", "fecha_test_drive", "proyecto" }
   • URL del Webhook: https://hook.us2.make.com/qo8btathlbc1kr3u26qh461cnv956qok
   • Flujo: Landing → ChatWidget → FastAPI → Groq (Tool Call) → 
     Supabase (INSERT 4 campos) + Make.com (POST 5 campos) → Gmail / Drive
   • Protección: La llamada al webhook está envuelta en try/except con 
     timeout=5s para no bloquear la respuesta al usuario si Make falla.

7. UX DEL CHATWIDGET (Pantalla de Bienvenida)
   ─────────────────────────────────────────────
   • Estado Inicial: Al abrir el chat, se muestra una pantalla de bienvenida
     con el logo de Velocity Motors y el botón "Iniciar Conversación".
   • No hay auto-start: El micrófono y la IA no se activan hasta que el
     usuario haga clic en el botón, mejorando la experiencia.
   • Al iniciar, la IA saluda y pregunta qué modelo le interesa.

FLUJO COMPLETO DEL SISTEMA (End-to-End)
================================================================================

1. El usuario entra a la Landing Page y ve el catálogo de vehículos.
2. Hace clic en el botón de chat (ícono flotante). Ve la pantalla de bienvenida.
3. Presiona "Iniciar Conversación". La IA saluda y pregunta qué modelo le interesa.
4. El ChatWidget envía el texto al backend (POST /chat-voz) con su session_id.
5. FastAPI inyecta la FECHA ACTUAL (datetime) al System Prompt y envía a Groq.
6. El LLM sigue el flujo guiado: Modelo → Fecha → Nombre → WhatsApp.
7. Cuando la IA recolecta los 4 datos, ejecuta Tool Calling:
   a) guardar_lead_test_drive(nombre, whatsapp, modelo_auto, fecha_test_drive)
   b) Supabase INSERT → Guarda los 4 campos en la tabla leads.
   c) requests.post() → Envía los 5 campos al Webhook de Make.com.
   d) Make.com dispara las automatizaciones (email, sheets, etc).
8. La IA confirma la cita con fecha completa (DD/MM/AAAA) y bloquea el chat.
9. El administrador accede a /admin, se autentica con Supabase Auth, y ve 
   el Dashboard con KPIs y la tabla de leads (ahora con modelo y fecha).
   Puede exportar todo a Excel.
